# Latvia vACC Knowledgebase

This collection of resources is a guide and source of theoretical knowledge (basically a Wiki) for Air Traffic Control students of Latvia vACC on the VATSIM Network as well as anyone else curious or interested in expanding their knowledge about the work that happens behind the scopes in EVRR FIR. If you are here for the first time, just click one of the cards below to find out more about topics that interest you!

The Knowledgebase is permanently hosted at [kb.lv-vacc.org](https://kb.lv-vacc.org).

## Self-hosting

This project is built with `Nextra` on top of `Next.js` and therefore `Node.js` and most pages are written in `MDX`. To self-host, clone the repository and run the following commands:

- `npm install` or `pnpm install` to install all dependencies.
- `npm run dev` or `pnpm dev` for the development server to start.

The project can be built by running `npm run build` or `pnpm build`.
